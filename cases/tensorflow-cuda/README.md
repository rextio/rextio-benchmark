# TensorFlow CUDA profile

This is documentation-only scaffolding for a future Linux/WSL2 NVIDIA run.
CUDA is not built or measured by the `cpu` scripts, and this repository makes
no support, certification, kernel-activity, transfer-profile, or speedup claim
from the macOS host.

Any future case must preserve `support_claim=false`,
`certification_ready=false`, `kernel_activity_verified=false`, and
`runtime_transfer_profiled=false` until separately promoted evidence says
otherwise.
